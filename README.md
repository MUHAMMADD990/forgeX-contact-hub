# FORGEX Engineering & Manufacturing Solutions Contact Hub

This project is a mobile-first digital business card for FORGEX Engineering & Manufacturing Solutions. It serves as a contact hub, providing essential information and contact actions for users.

## Project Structure

```
forgeX-contact-hub
├── assets
│   └── logo.svg          # Logo for the brand
├── index.html            # Main HTML document
├── script.js             # JavaScript for interactive elements
├── styles.css            # CSS styles for the page
└── README.md             # Project documentation
```

## Setup Instructions

1. **Clone the repository**:
   ```
   git clone <repository-url>
   ```

2. **Navigate to the project directory**:
   ```
   cd forgeX-contact-hub
   ```

3. **Open `index.html` in your web browser** to view the digital business card.

## Usage Guidelines

- The digital business card is designed to be responsive and mobile-friendly.
- Users can easily access contact information and services offered by FORGEX.
- Interactive elements are managed through JavaScript in `script.js`.

## Design and Functionality

- The project utilizes semantic HTML for better accessibility and SEO.
- The CSS in `styles.css` ensures a cohesive brand identity and a visually appealing layout.
- The JavaScript file `script.js` handles all interactive features without any complex routing logic.
